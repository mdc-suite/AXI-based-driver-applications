# Applications
This folder contains examples of applications edge detection in MDC tool-chain.
All generated files are organized within this directory, which includes the subdirectories `baseline/` and `custom/`.

## Folder contents
* **`baseline/`**:  Visualize the graphical network contains the `.xdf` file (network definition) and `.xdfdiag` (graphical metadata).
* **`custom/`**: contains the generated CAL actor files for each function/operator.
