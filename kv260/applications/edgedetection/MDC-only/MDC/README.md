# Applications
This folder contains examples of applications edge detection in MDC tool-chain.
All generated files are organized within this directory, which includes the subdirectories `networks/` and `actors/`.

## Folder contents
* **`networks/`**:  Visualize the graphical network contains the `.xdf` file (network definition) and `.xdfdiag` (graphical metadata).
* **`actors/`**: contains the generated CAL actor files for each function/operator.
